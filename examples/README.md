# Examples

Realistic, condensed example sessions showing how `policy-checker` behaves at
each phase. All companies, people, and data in these examples are **fictional
and anonymized** — real company names like Stripe or Google Analytics appear
only as third-party services, which is how they'd appear in real usage.

| Example | Scenario | Shows |
|---|---|---|
| [example-session-saas.md](example-session-saas.md) | B2C web SaaS with subscriptions, Stripe, Mailchimp, Google Analytics, EU + US users | Full 5-phase flow: interview answers, audit findings, selection checklist, a drafted document excerpt, placeholders list, compliance summary |

Read these before using the skill to know what to expect, and use them as a
format reference when contributing new examples.
